## Known problems → fix
- `exec ...entrypoint.sh: no such file or directory` → CRLF line endings. `.gitattributes` forces LF; fix an old checkout with
  `git add --renormalize . && git checkout -- infra`.
- `Bind for 0.0.0.0:8081 failed` → another app uses the port: set `NGINX_PORT` in `.env` and `BASE_URL` in `indico.conf`.
- Docker Hub `TLS handshake timeout` → transient; `docker pull` the base image again, then rebuild.
- Paths like `C:/Program Files/Git/opt/...` → Git Bash rewrote a container path; prefix the command with `MSYS_NO_PATHCONV=1`.
- 401/403 on every API call → tokens were regenerated by a reset; re-run `env-reset` and re-read `.env.test`.
- Seed fails with an import error → the Indico version changed. The app image is pinned to 3.3.14 (`worker/Dockerfile`,
  compose `args.tag`); never use `latest`.
